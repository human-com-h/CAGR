# Security

Do not post credentials in Issues. Report a security concern privately to the corresponding author through the contact in the manuscript. If a token is exposed, its owner must revoke it before history remediation. Repository scans reject common credential formats, private keys and machine-specific account paths.

The reproduction tools download only pinned public provider resources and verify hashes. They never submit Kaggle jobs, upload models or read local authentication stores. CUDA compilation uses the supplied source and existing toolchain. Inspect upstream model/data licenses before use.

Full paper documents are outside the approved public scope. Follow
[PUBLICATION_POLICY.md](PUBLICATION_POLICY.md) and scan both complete Git history
and release archives before publication. A paper supplied for internal analysis
must not be uploaded under a general code-release authorization.
